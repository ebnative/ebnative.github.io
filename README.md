# Ebru — graphic design portfolio

Static, image-led portfolio for Ebru. Browse selected work by project and design format. This repository contains only optimized site assets, not editable design sources or the private working archive.

Personal fan-art posters are independent, unofficial work and are not affiliated with the television series or its rights holders. Client and brand names identify the projects shown; they do not imply endorsements.

To preview locally: `python3 -m http.server 8765 --bind 127.0.0.1` from this directory. No build dependencies are required.

Current site: 79 works, including 44 Midjourney image studies, a responsive seven-image hero, a rotating 5 × 3 selection, a complete archive, and a separate German About/resume page. The downloadable resume omits personal contact details. Holographic material attribution and MIT license are in `vgpu-LICENSE.txt`.
